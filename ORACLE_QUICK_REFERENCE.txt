ORACLE CLOUD CONFIGURATION (Security List)
================================================================================

CRITICAL: Configure in Oracle Console → Network & Security:

1. INGRESS RULES (allow incoming):
   - Port 22 (SSH)          → Source: 0.0.0.0/0
   - Port 3001 (Dashboard)  → Source: 0.0.0.0/0
   - Port 57299 (Discord)   → Source: 0.0.0.0/0

2. EGRESS RULES (allow outgoing):
   - HTTPS (443)            → Destination: 0.0.0.0/0

This is REQUIRED for bot to connect to Discord API!
